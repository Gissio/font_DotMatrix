DotMatrix is a font inspired by the dot matrix printers of the 1980s, capturing the essence of the printing technologies from that era. It's perfect for evoking a retro or nostalgic feel, rendering ASCII/ANSI art, or use within code editors. For true scale, use 10 point text.

It features:

  • Character Set: Includes 650 characters featuring the full set from the Epson FX-80 printer, DOS code page 437, Google Fonts Latin Core, Greek Core, Cyrillic Core, and Hebrew. Note, the italic subset is limited to 191 characters due to historical constraints.
  • Dot Jitter: Simulates the inaccuracy of the printing head for an authentic look.
  • Epson FX-80 Modes: Mapped to different DotMatrix font families:
    Epson FX-80 Mode Pitch (cpi) DotMatrix Font Family
    Pica 10 DotMatrix SemiExpanded
    Elite 12 DotMatrix
    Compressed 17.16 DotMatrix Condensed
    Expanded Pica 5 DotMatrix UltraExpanded
    Expanded Elite 6 DotMatrix ExtraExpanded
    Expanded Compressed 8.58 DotMatrix Expanded
    Emphasized Pica 10 DotMatrix Emphasized SemiExpanded
    Emphasized Expanded Pica 5 DotMatrix Emphasized UltraExpanded
    • "Double-strike" is represented by the Bold style.
    • "Italic" corresponds to the Italic style.
    • "Proportional mode" is mapped to the respective Prop font families.
  • Fixed Print Modes: Like the printer, every print mode is a static font.
